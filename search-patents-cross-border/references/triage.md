# 大量命中的低 token 分层复筛

在 [coverage.md](coverage.md) 所定检索方案内，将“结果列表收集完毕”和“逐件阅读文献”分别统计。检索结果导出保留为原始文件，不整批送入模型；正常页面翻页或完整导出由站点限制决定，脚本不负责绕过站点访问规则。未能读完或导出全部结果时仍标为部分覆盖。

1. **原始命中：**各批保存原始 CSV、检索式、日期边界和分页/导出验收日志；不丢弃未筛中的号码，统计原始行数和缺失公开号。
2. **规则初筛：**用 `scripts/shortlist_metadata.py` 对导出的公开号归一化去重，抽取标题、摘要、IPC/CPC、申请人、优先权日及来源；依据用户产品词和结构词标记 `candidate`。其余（含元数据不全及词汇不符）标记 `manual_review`，**不是“已读全文排除”**。术语和申请人别名由检索任务确定，不把“头部公司”当成自动证明的事实。脚本不自动合并同族、不打新颖性/侵权分数。
3. **人工校正召回：**复核 `manual_review` 中的空字段、低频术语、重点公司以及按批次抽查的样本；如发现相关漏项，扩展词表并重新运行初筛。报告披露抽查范围和仍未复核的数量，不可将抽样审阅说成全部逐件阅读。
4. **候选复筛：**仅对通过初筛及人工补选的候选，逐件打开公开页，读**摘要和独立权利要求**；不批量塞入说明书。对同族只核对代表文本，涉及实质差异再读其他成员；存疑不强行合并。只有被用户要求或关键特征存疑时，再读从属权利要求和相关说明书段落。
5. **交付：**最多 50 个已核验权利要求且有来源的相关专利族，单件列中文概述、申请人、发明人及权利要求号；另外给出原始命中数、号码去重数、规则候选数、人工复核数、权利要求已读数、最终族数及未覆盖页数。不能把脚本标记为 `candidate` 当成最终相关性结论。

示例（CSV 至少含 `publication_number`/`公开号`；其他字段缺少时保留空值，需人工核对；可重复 `--input`、`--product`、`--structure`、`--applicant`）：

```powershell
python -X utf8 scripts/shortlist_metadata.py --input .\google-batch.csv --input .\wipo-batch.csv --output .\triage.jsonl --audit .\triage-audit.json --product '四向穿梭车' --product 'four-way shuttle' --structure '顶升' --structure 'lifting' --applicant 'Mecalux'
```

`triage.jsonl` 每行是一个**公开文本**的简明字段记录，并带 `triage` 和 `claims_checked: false`；不是最终报告所需 `families` JSON。不要把 JSONL 全文直接加载到模型上下文：先看审计计数，再分批读取候选短字段，最后逐件获取原文证据。脚本只识别少量标准列名（见源码 `FIELDS`），站点导出列名不兼容时先做显式映射；来源网站的点击数、导出是否截断、同族真实性和权利要求均须单独验证。
